# Samples del Compositor

Archivos `.mp3` generados con `npm run fetch-compositor-samples`.

Fuentes (repositorio [Tonejs/audio](https://github.com/Tonejs/audio)):

| Archivo | Origen |
|---------|--------|
| `piano-c4.mp3` | Salamander grand piano C4 |
| `kick.mp3`, `snare.mp3`, `hihat.mp3` | Acoustic drum kit |
| `guitar-note.mp3` | Berklee — cuerda Mi grave |
| `guitar-strum.mp3` | Berklee — acorde (rasguido) |

No editar a mano; volver a ejecutar el script si hace falta actualizar.
